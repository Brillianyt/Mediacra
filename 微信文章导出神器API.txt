为了方便第三方开发人员进行个性化定制，本网站将其主要功能（包括但不限于公众号查询、历史文章列表查询、文章下载等）提供 API 以供接入。

注意：目前接入 API 免费，后续会根据实际情况动态调整，不排除会改为收费模式。

如果你的调用量比较大的话，推荐进行私有部署。

密钥

以下所有 API 如无特殊说明，均需要携带密钥进行调用。密钥可通过以下两种方式传输：

a. 通过自定义请求头 X-Auth-Key

b. 通过 name 为 auth-key 的 Cookie

调用 API 的密钥与本网站的登录已集成在一起，也就是说，你在该网站扫码登录之后会自动刷新 API 密钥。

由于该密钥与网站用的同一套体系，网站的登录信息失效时，对应的 API 密钥也将失效。

4. 获取文章内容

简要描述

获取文章内容，支持 html / markdown / text / json 格式

备注:

此接口不需要 API 密钥

请求URL:

https://down.mptext.top/api/public/v1/download

请求方式:

GET

参数:

参数名	参数位置	强制	默认值	类型	说明	备注
url	query	是	N/A	String	文章链接	需经过url编码
format	query	否	html	String	输出格式	支持 html / markdown / text / json 格式
返回示例:


https://down.mptext.top/api/public/v1/download?url=https://mp.weixin.qq.com/s/tr38EieqyftubIx2FMWUWw&format=html
